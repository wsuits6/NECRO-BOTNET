# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability within this project, please report it responsibly:

1. **Do NOT** open a public GitHub issue for security vulnerabilities
2. Email security concerns to: wsuits6@gmail.com
3. Include detailed steps to reproduce the issue
4. Allow reasonable time for a response before public disclosure

## Authorized Use Only

This software is designed for **authorized security testing and educational purposes only**. 

### Before Using This Software

- Ensure you have **written authorization** from the system owner
- Verify you are operating within **legal boundaries** of your jurisdiction
- Use only in **controlled environments** or during **authorized engagements**
- Follow your organization's **rules of engagement**

### Legal Considerations

- Unauthorized access to computer systems is illegal under laws such as:
  - Computer Fraud and Abuse Act (CFAA) - United States
  - Computer Misuse Act 1990 - United Kingdom
  - Similar laws in other jurisdictions
- Violations may result in criminal prosecution and civil liability
- The authors assume no responsibility for misuse of this software

## Responsible Disclosure

If you find vulnerabilities using this software:

1. Report them to the affected party promptly
2. Do not exploit vulnerabilities beyond what is necessary to demonstrate the issue
3. Do not access or modify data without authorization
4. Provide sufficient information to reproduce and fix the issue
